# 🎓 EduTech - Gerenciamento de Cursos Online

Projeto de **gerenciamento de uma plataforma de cursos online**, com foco principal em **banco de dados relacional**(70% do projeto) e **consultas SQL avançadas**.

O desenvolvimento prioriza a **modelagem de dados**, integridade relacional e análise de informações, utilizando o **PostgreSQL** como tecnologia central e o **Python**(30% do projeto) como ferramenta auxiliar para automação e geração de dados.

## 🎯 Objetivo do Projeto

Este projeto tem como objetivo aprofundar conhecimentos práticos em:

* Modelagem de dados relacional
* Criação de **Diagramas Entidade-Relacionamento (DER / ER)**
* Escrita de **consultas SQL complexas**
* Uso de **PostgreSQL** em cenários próximos ao mundo real
* Integração do banco de dados com **scripts em Python**

O projeto está sendo desenvolvido como **estudo prático e portfólio técnico**.

---

## 🧠 Escopo Técnico

A distribuição do foco do projeto é:

* **70% – SQL / PostgreSQL**

  * Modelagem do banco de dados
  * Criação de tabelas, chaves primárias e estrangeiras
  * Relacionamentos complexos
  * Consultas avançadas (`JOIN`, `GROUP BY`, `HAVING`)
  * Análise e extração de dados

* **30% – Python**

  * Scripts auxiliares
  * Geração de dados fictícios com a biblioteca **Faker**
  * Inserção automatizada de dados no banco
  * Apoio à validação e testes das consultas SQL

---

## 🗂️ Modelagem de Dados

O sistema possui uma **modelagem de dados estruturada**, representada por um **Diagrama Entidade-Relacionamento (ER)**, contemplando entidades como:

* Alunos
* Instrutores
* Matrículas
* Cursos
* Modulos
* Aulas
* Categoria_cursos
* Especialidades
* Instrutor_especialidades

O diagrama serve como base para a criação e evolução do banco de dados.
